# Synthetic examples

Every shape, reference, part number and coordinate here was created specifically for this public demonstration. These files contain no real project, hardware design, production board, supplier secrets or user data. They are offered under the repository's MIT license and are not manufacturing files for a working product.

The demo is a 40 × 30 mm rectangle with three components on top (R1, R2, U1), two on bottom (C1, D1), and two drill holes. R1 and R2 share a 10k resistor material; D1 is DNP. Import `demo-*` together. `kicad-sample.pos` is an alternative placement-format example; do not import it alongside `demo-cpl.csv` unless explicitly selecting one placement table.
